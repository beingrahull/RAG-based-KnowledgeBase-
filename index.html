Under the hood

Four decisions that make it production-grade.

01 / SECURITY

Multi-tenant by design

JWT in HTTP-only cookies and strict per-user data isolation. Users only ever query their own document silos.

02 / RETRIEVAL

Hybrid search + reranking

Semantic embeddings plus keyword search, then a cross-encoder reranks the top-K so the LLM sees dense, relevant context.

03 / GROUNDING

Citations or silence

Strict JSON-schema output forces every claim to carry a citation from the source. No citation, no claim.

04 / RESILIENCE

Ingestion that survives reality

Batching, exponential backoff on 429/503, and async processing so large PDF corpora never block the API.

“If you can’t measure it, you didn’t build it.”

A custom evaluation suite on golden datasets tracks Recall@K, so chunk size, overlap, and embedding choices are tuned with data instead of guesses.
